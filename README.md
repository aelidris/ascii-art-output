Usage:

To run the program, use the following syntax:

go run . [OPTION] [STRING] [BANNER]

For example:

go run . --output=<fileName.txt> something standard

Directory Structure:

compare: Contains all testing files.

funcs: Contains all functions used in this program.

shadow.txt, standard.txt, and thinkertoy.txt: Contain the source files that print ASCII ART characters from 32 to 126 in the ASCII code.
